## 🌷 How I approach data problems

1. **Understand** — clarify the question and what the data represents.
2. **Inspect** — check structure, missing values, and data quality.
3. **Prepare** — clean and transform the data.
4. **Analyse** — explore patterns and interpret results carefully.
5. **Communicate** — explain findings and limitations clearly.
